# IyoJobs — مواصفات المنتج v0.1

## الهدف وحدود الإصدار

منصة مستقلة تربط المرشحين بأصحاب العمل عبر بحث متعدد اللغات، ملفات مهنية، تحليل CV قابل للتصحيح، مطابقة مفهومة، رسائل وإشعارات Android. العالمية تعني قابلية التوسع للغات والبلدان، لا وعداً بإطلاق قانوني متزامن في جميع الدول. الإصدار التجريبي يبدأ ببيانات صناعية ثم مجموعة محدودة بعد معالجة بوابات الأمان.

اللغات الأولى: العربية والإنجليزية والفرنسية. RTL كامل للعربية؛ لا ترجمة آلية صامتة للسيرة أو إعلان الوظيفة. النص الأصلي محفوظ والنسخة المترجمة موسومة. البلد ISO-3166-1 alpha-2، العملة ISO-4217، التواريخ UTC مع العرض حسب منطقة المستخدم. الاسم IyoJobs أكدّه المالك؛ اسم الحزمة التقني المؤقت talent-atlas.

## المستخدمون والصلاحيات

| الدور | قدراته | الحدود |
|---|---|---|
| زائر | بحث وعرض وظائف منشورة | لا CV ولا رسائل ولا بيانات مرشحين |
| مرشح | ملفه وسيرته وطلباته وتفضيلاته | لا يرى ملفات غيره ولا يغير قرار الشركة |
| صاحب شركة | ملف الشركة والوظائف وطلبات وظائفها | لا يتصفح CV خاصاً بلا تقديم/موافقة |
| مسؤول توظيف | صلاحيات عضوية محددة | مرحلة لاحقة بعد دعوة موثقة |
| مشرف منصة | مراجعة البلاغات والتحقق والتعليق | سجل تدقيق وإجراءات وصول استثنائي |

لا يتيح التسجيل اختيار دور مشرف. صاحب العمل غير الموثق لا ينشر علناً في النسخة الإنتاجية. المرحلة البرمجية الحالية تسمح بالنشر داخل بيئة تطوير فقط لتجربة المسار.

| الرمز | المتطلب | معيار القبول |
|---|---|---|
| ID-01 | تسجيل ودخول وخروج | كلمات مرور مشتقة، جلسات منتهية وقابلة للإبطال، لا إعادة أسرار بالـAPI |
| ID-02 | تحقق بريد واسترجاع وMFA للشركات | روابط أحادية الاستخدام وانتهاء واختبارات إساءة؛ مطلوب قبل beta العامة |

| JOB-01 | بحث وفلاتر | كلمة وبلد وremote وصفحات؛ نتائج خالية مفهومة ولا إدخال SQL |
| JOB-02 | دورة حياة | draft→review→published→closed؛ الإدارة ترفض إساءة؛ الحالي open/closed للتطوير |

| MAT-01 | مطابقة | عوامل قابلة للشرح، الإصدار مسجل، لا استخدام الاسم/الصورة/العمر/الجنس |
| MAT-02 | AI اختياري | fallback محدد، سقف تكلفة، وقت انتظار، مخطط JSON صارم، تقييم ar/en/fr |
| APP-01 | تقديم ومتابعة | تقديم واحد لكل مرشح ووظيفة؛ الحالة لا تتجاوز انتقالاتها |
| COM-01 | تواصل مهني | الطرفان فقط يقرآن الرسائل؛ منع الإرسال بعد انسحاب؛ إبلاغ وحظر قبل beta |
| NOT-01 | صندوق إشعارات | لكل مستخدم فقط؛ أحداث تكتب مع العملية نفسها |
| NOT-02 | Android push | موافقة المستخدم، تسجيل/تدوير token، عدم تكرار، payload بلا CV أو محتوى رسالة |
| PRIV-01 | تحكم بالبيانات | تنزيل نسخة وحذف ضمن سياسة retention معلنة واختبار استعادة النسخ الاحتياطية |
| I18N-01 | تجربة متعددة اللغات | سلاسل خارج الكود، RTL، قارئ شاشة، تكبير الخط، أخطاء مترجمة |

## الرحلات

المرشح: تسجيل وتحقق → اختيار لغة → إنشاء ملف → رفع/لصق CV → مراجعة الاقتراحات → بحث وفهم المطابقة → تقديم واضح بالمعلومات التي ستصل للشركة → متابعة ورسائل → سحب الطلب أو إدارة البيانات.

الشركة: تسجيل وتحقق → إثبات الشركة → وظيفة ومسؤوليات وراتب/عملة/دورية اختيارية واضحة → مراجعة ونشر → طلبات تخص الشركة → قرار بشري وتواصل → إغلاق الوظيفة. لا يوجد رفض آلي بسبب score ولا auto-apply.

Android: تسجيل → بحث محفوظ محلياً → تفاصيل ومطابقة → تقديم → inbox → إعدادات اللغة والخصوصية والإشعارات. الرمز السري لا يخزن في نص صريح؛ انتهاء الجلسة يعيد المصادقة دون فقدان مسودة محلية غير حساسة. Deep links تعيد التحقق من الصلاحيات.

## البيانات والذكاء الاصطناعي

التنفيذ الأول يقبل نص CV فقط ويستخرج قاموس مهارات صغير محلياً؛ لا يخزن النص ولا يرسله لخارج الجهاز المضيف. المطابقة الحالية نسبة تغطية المهارات المطلوبة وليست AI أو احتمال توظيف. يظل تأكيد المهارات بيد المستخدم.

المرحلة التالية تستخدم مزوداً خلف واجهة داخلية، بعد إزالة المعرفات غير اللازمة والحصول على موافقة واضحة وتحديد retention لدى المزود. مخرجات CV/الوصف بيانات غير موثوقة: لا أدوات تنفيذ، لا أسرار في prompt، لا جلب روابط من السيرة، لا قبول ادعاءات خبرة غير مسندة. يخزن model_version وprompt_version ووقت المعالجة ومبررات المطابقة. التقييم يشمل extraction precision/recall لكل لغة وتحيزات بيانات الاختبار، مع مجموعة ذهبية يراجعها بشر.

## متطلبات التشغيل

أهداف beta المقترحة وليست نتائج مقاسة: p95 قراءة <500ms وكتابة <800ms عند 50 مستخدماً متزامناً؛ معالجة CV خلال 60 ثانية عند الحمل المتفق عليه؛ توافر 99.5%، RPO 24h وRTO 4h. إرسال push هدف <30 ثانية بعد الحدث؛ وصوله غير مضمون من نظام التشغيل أو الشبكة. اختبار حمل ونسخ احتياطي واستعادة شرط لقبول هذه الأرقام.

قياس funnel دون نصوص CV: بحث→عرض→تقديم؛ معدل أخطاء؛ عمر queue؛ فشل push؛ تكلفة AI لكل تحليل؛ عدد البلاغات. حذف المعرفات الحساسة من traces. لا بيع بيانات المرشحين أو استخدامها لتدريب نماذج افتراضياً.

## خارج MVP

مدفوعات واشتراكات، فيديو مقابلات، شبكة منشورات عامة، scraping غير مرخص، بحث أصحاب العمل في جميع السير، نشر عالمي متعدد المناطق، تأشيرات آلية أو قرارات أهلية. تضاف فقط بعد تحقق ملاءمة المنتج والحقوق والميزانية.

## قرارات تحتاج تحديداً قبل beta

الكيان القانوني والأسواق الأولى؛ سياسة العمر؛ منطقة الاستضافة؛ الميزانية الشهرية؛ مزود البريد وAI؛ حساب Firebase وAndroid applicationId؛ سياسة احتفاظ متوافقة مع الأسواق؛ العلامة والنطاق. هذه لا تمنع بناء النواة محلياً، لكنها تمنع ادعاء جاهزية الإنتاج.
