## ما أثبته الفحص

المشروع أداة مساعدة للباحث عن عمل: يجمع فرصاً من مصادر متعددة، يقيّم الملاءمة، يخصص السيرة، يصدر PDF ويتتبع الطلبات بما في ذلك تكامل البريد. يذكر README أن التقديم يبقى بيد المستخدم. هذه وظائف مرجعية للمنتج، وليست إذناً بإعادة استخدام التنفيذ. [README](https://github.com/DaKheera47/job-ops/blob/main/README.md).

تُنظّم الحزم عبر npm workspaces: orchestrator وshared وextractors وcareer-boards وdocs-site. هذا الفصل مفيد لاستيعاب مزودي مصادر مختلفين لكنه يضيف حدود اعتماد ومخاطر تحديث متعددة. [الحزم الجذرية](https://github.com/DaKheera47/job-ops/blob/main/package.json).

حزمة orchestrator تجمع React وVite للعميل مع Express للخادم، Drizzle وbetter-sqlite3 للتخزين، Vitest للاختبارات وBiome للفحص. وجود هذه المكتبات لا يثبت جودة الاختبارات أو عزل الصلاحيات. [حزمة orchestrator](https://github.com/DaKheera47/job-ops/blob/main/orchestrator/package.json).

ملف قاعدة البيانات يتضمن users وtenants وعضويات ومعلومات اشتراكات ووظائف وأحداث تتبع؛ لذلك وصف المشروع بأنه أحادي المستخدم سيكون غير دقيق. لم نتحقق من كل استعلام تفويض أو ضمان عزل tenants. مخطط IyoJobs الجديد مستقل وأبسط في المرحلة الأولى. [المخطط المفحوص](https://github.com/DaKheera47/job-ops/blob/main/orchestrator/src/server/db/schema.ts).

Compose يعرض خدمة التطبيق مع تخزين دائم وhealthcheck وموارد للتصدير. هذا نمط نشر ذاتي، وليس دليلاً على توافر متعدد المناطق أو تعافٍ تلقائي أو اختبار تحميل عالمي. [Compose](https://github.com/DaKheera47/job-ops/blob/main/docker-compose.yml).
