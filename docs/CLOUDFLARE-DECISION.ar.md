# قرار معماري: استضافة IyoJobs على Cloudflare

الحالة: **مقترَح — لم يُنفَّذ ولم يُنشر شيء**. التاريخ: 2026-11-01.
المصدر: توثيق Cloudflare الرسمي كما أعادته أداة البحث في التوثيق أثناء الجلسة، مع بنود غير محقَّقة مذكورة صراحةً أدناه.

## 1. السياق

- الواجهة الخلفية الحالية: FastAPI + SQLite (وحدة واحدة modular monolith)، تعمل محلياً وفي Docker، واختباراتها (10) ناجحة.
- لا يوجد أي نشر عام ولا مهمة نشر في CI. النشر إلى الإنتاج يتطلب موافقتك الصريحة على الإصدار المحدد (SECURITY.md).
- موارد Cloudflare الموجودة في حسابك: Workers باسم `iyo` و`iyo-designer-com` (لمشروع آخر — لن نمسّهما). لا توجد قواعد D1 ولا KV. خدمة R2 **غير مفعّلة** (رد 403 «فعّلها من لوحة التحكم»).

## 2. الخيارات

| | الخيار | تغيير الكود | الحالة |
|---|---|---|---|
| **أ** | Python Worker + FastAPI (ASGI) + D1 | متوسط: طبقة البيانات تتحول من `sqlite3` المتزامن إلى ارتباط D1 غير المتزامن، ونقل قفل الخيوط | **غير محقَّق** — انظر §4 |
| **ب** | Worker بلغة TypeScript (Hono) + D1 | كبير: إعادة كتابة الخادم (~330 سطراً + المطابقة) | مضمون تقنياً، أعلى كلفة |
| **ج** | Cloudflare Containers تشغّل صورة Docker الحالية | أقل تغيير | قرص مؤقت (ephemeral) فتضيع بيانات SQLite — **غير مناسب** كقاعدة بيانات؛ ويحتاج Workers Paid |
| **د** | استضافة API خارجية + PostgreSQL، والواجهة على Cloudflare | متوسط (SQLite→PostgreSQL) | مسار إنتاج تقليدي؛ يضيف مزوداً ثانياً |

### ما تقوله الوثائق (ملخص)
- Python Workers تدعم FastAPI عبر ASGI، لكنها تعمل على Pyodide؛ الخيوط (threading) غير فعّالة.
- D1 قاعدة بدلالات SQLite، واجهتها غير متزامنة، والمعاملات عبر `batch`، سقف 10GB للقاعدة، ومعالجة أحادية الخيط لكل قاعدة.
- الحد الافتراضي لوقت المعالج: 10ms في الخطة المجانية، 30s في المدفوعة.
- Workers Static Assets تخدم الواجهة مع fallback لتطبيقات الصفحة الواحدة.
- Workers Builds ينشر فرع الإنتاج تلقائياً — **يتعارض** مع شرط موافقتك اليدوية، لذلك لن نستخدمه للإنتاج.

## 3. القرار المقترح

1. **الواجهة (web/)**: Workers Static Assets الآن، مستقلة تماماً عن اختيار الواجهة الخلفية. المسار `/api/*` هو العقد بين الواجهة والخادم.
2. **الواجهة الخلفية**: لا نقرر بين أ وب ود قبل إجراء **اختبار التوافق** (`spikes/python-workers-compat/`) على جهازك. نتيجته تحسم أ مقابل ب.
3. **قاعدة البيانات**: D1 مرشّحة لأن المخطط SQLite-متوافق، لكن **لا ننتقل تلقائياً**. PostgreSQL يبقى بديلاً قائماً إذا ظهر أن D1 لا يكفي (استعلامات النص الكامل، التزامن، أو الحجم).
4. **الملفات الخاصة (السير الذاتية)**: R2 بقيم خاصة (بلا وصول عام). يتطلب منك تفعيل R2 من لوحة التحكم — **لا نرفع أي CV قبل ذلك ولا قبل مسار الموافقة المخصص**.
5. **البيئات**: dev محلي، staging باسم مستقل (`iyojobs-web-staging`)، production باسم وإعدادات منفصلة. أسرار كل بيئة في Cloudflare/GitHub Secrets فقط.

## 4. غير محقَّق (يجب ألا يُعامل كحقيقة)

- هل `hashlib.scrypt` متاح في Pyodide وكم يستغرق؟ (على الأرجح يتجاوز 10ms → خطة مدفوعة أو تغيير KDF مع ترحيل كلمات المرور.)
- هل يعمل `sqlite3` هناك؟ (حتى لو عمل فهو في الذاكرة فقط.)
- زمن بدء Python Worker والحد على حجم الحزمة.
- هل حماية الموافقة في GitHub Environments (required reviewers) متاحة لمستودعك حسب خطتك؟ على المستودعات الخاصة قد تتطلب خطة مدفوعة. **لم أتحقق من خطتك.**
- محاولة تشغيل الاختبار داخل بيئة الجلسة فشلت بحجب DNS (`pyodide-capnp-bin.edgeworker.net`)، فلا أرقام لدي.

## 5. الكلفة المتوقعة (تقدير، يُراجَع)

- Workers Paid: حوالي 5 دولارات شهرياً، على الأرجح لازمة بسبب حد المعالج (خيار أ).
- D1 والأصول الثابتة: ضمن الطبقة المجانية في المراحل الأولى.
- R2: تفعيله مجاني للبدء، والتخزين مدفوع حسب الاستعمال.

## 6. مسار الترحيل

1. تثبيت العقد: بادئة `/api/v1`، نقطة تفاصيل الوظيفة، الحقول الناقصة (التاريخ، المصدر، الأهلية، «متاحة عالمياً»).
2. إصلاح ثغرات التدقيق قبل أي نقل: الترتيب الزمني، تحديد المعدل لكل حساب/IP، معاملات scrypt، جلسات HttpOnly+CSRF.
3. نظام ترحيلات مرقّمة للمخطط (`migrations/0001_*.sql`) تعمل على SQLite محلياً وعلى D1 بنفس الملفات.
4. تشغيل staging على D1 ببيانات اصطناعية فقط، مع اختبارات العقد نفسها.
5. خطة التراجع: الواجهة تُعاد لإصدار سابق (Workers versions)، والبيانات: تصدير D1 قبل كل ترحيل.

## 7. بوابة القرار

لا يتغير شيء قبل: (1) نتيجة الاختبار من جهازك، (2) تأكيدك لخطة Cloudflare وتفعيل R2 إن لزم، (3) موافقتك على الخيار. النشر إلى الإنتاج ممنوع تلقائياً، ويتطلب عرض إصدار محدد وفحوصاته وترحيلاته وكلفته وخطة تراجعه ثم موافقتك الصريحة.
